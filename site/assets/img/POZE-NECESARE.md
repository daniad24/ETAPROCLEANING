# Poze de pus în acest folder

Pune pozele cu exact aceste nume (jpg, ideal cel puțin 1600 px pe latura mare). Până apar, site-ul afișează un loc marcat.

## Înainte / după (secțiunea „Rezultate”)
Fiecare pereche trebuie fotografiată din același unghi și la aceeași încadrare, altfel slider-ul nu se aliniază.

| Tab | Înainte | După |
|---|---|---|
| Scaune textile | ba-scaune-inainte.jpg | ba-scaune-dupa.jpg |
| Mochetă | ba-mocheta-inainte.jpg | ba-mocheta-dupa.jpg |
| Motor | ba-motor-inainte.jpg | ba-motor-dupa.jpg |
| Plafon | ba-plafon-inainte.jpg | ba-plafon-dupa.jpg |
| Piele | ba-piele-inainte.jpg | ba-piele-dupa.jpg |

Tab-urile se modifică din `main.js`, în lista `BA_PAIRS`.
